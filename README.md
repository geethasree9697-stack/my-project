# UPI Fraud Detection System

## 📌 Project Description

This project detects fraudulent UPI transactions using Machine Learning techniques. It uses the XGBoost algorithm and PaySim dataset to identify suspicious activities.

## 🚀 Features

* Detects fraud transactions
* High accuracy using XGBoost
* Web interface using Flask
* Real-time prediction

## 🛠️ Technologies Used

* Python
* XGBoost
* Flask
* Pandas, NumPy
* PaySim Dataset

## 📊 Dataset

PaySim dataset (simulated financial transactions)

## ⚙️ How to Run

1. Clone the repository
2. Install required libraries:
   pip install -r requirements.txt
3. Run the app:
   python app.py
4. Open browser and go to:
   http://127.0.0.1:5000/
